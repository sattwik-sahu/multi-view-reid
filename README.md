### Training

To start training a model, use the `train` script provided.

```bash
train model=vit_tiny dataset=veri776 lr=1.5e-4
```

## Contributing

To contribute to the project, follow the steps below.

1. Clone the repo
  ```bash
  git clone https://github.com/sattwik-sahu/multi-view-reid.git
  ```
2. Install the packages using `uv`
  ```bash
  uv sync --all-groups
  ```
3. Now you can add new features
